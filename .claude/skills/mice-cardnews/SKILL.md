# MICE 카드뉴스 스킬

## 목적
공공기관(서울관광재단, 킨텍스, 마이스투데이 등) MICE 관련 뉴스를 원고 → 이미지 선정 → 디자인까지 일관된 스타일로 카드뉴스화한다.

## 1. 원고 작성 규칙
- 기사 원문을 그대로 베끼지 않는다. 반드시 새 문장으로 패러프레이즈한다.
- 직접인용은 15단어 미만, 출처당 1회로 제한한다.
- 카드 4, 5장 분량(표지 + 상세 3, 4장)으로 핵심만 나눈다.
- 관계자 코멘트는 직접인용하지 않고 "~라는 소감을 전했다" 식으로 요약한다.

## 2. 이미지 사용 규칙 (저작권)
다음은 사용하지 않는다:
- "사진 제공=OOO" 형태의 보도용 배포 이미지 (언론 보도 목적으로만 허용된 것)
- iStock/Getty 등 유료 스톡 워터마크가 보이는 이미지
사용 가능:
- Unsplash 등 명확한 무료 라이선스(상업적 사용 허용) 이미지
- 사용자가 직접 업로드한 실사 사진
- 적절한 이미지가 없으면 사진 없이 그라데이션 + 타이포그래피로 대체 (아래 3번 참고)

## 3. 디자인 시스템
- 캔버스: 1080 x 1350px (4:5, 인스타그램 세로)
- 폰트: 원티드산스(Wanted Sans). @font-face로 로컬 ttf 파일 로드 (레포의 /fonts 폴더 필요, Regular~Black 7종)
- 레이아웃:
  - 좌상단: 카테고리 배지(흰 배경, 어두운 텍스트, 둥근 알약 모양)
  - 본문: 화면 정중앙 배치, 반투명 다크 카드(rgba 60% 내외) 위에 흰색 텍스트
  - 사진이 없는 슬라이드는 주제에 맞는 그라데이션 배경 사용, 세트 전체는 하나의 포인트 컬러로 통일
- 표지: 작은 소제목(sub) → 큰 헤드라인 순서. 강조하고 싶은 문구를 큰 헤드라인 자리에 배치.

## 4. 한글 줄바꿈 (중요)
렌더링 엔진이 한글 어절 단위 자동 줄바꿈(word-break: keep-all)을 지원하지 않는 경우가 많다.
자동 줄바꿈에 맡기지 말고 문장을 자연스러운 의미 단위로 나눠 `<br>`로 직접 끊는다.
특히 "~습니다", "~합니다", "~했다" 같은 서술어 앞에서 줄이 끊기지 않도록 주의한다.
(렌더링 후 반드시 한 번 이미지로 확인해서 단어가 잘렸는지 검수한다.)

## 5. 산출물
- PNG 5장 (표지 포함)
- 인스타그램 피드용 캡션 3~5줄 + 출처 표기
- 저장 위치: /cardnews/YYYY-MM-DD-제목/ 폴더

## 6. 검수 체크리스트
- [ ] 문장이 원문 그대로 복사되지 않았는가
- [ ] 이미지 출처가 저작권 안전한가
- [ ] 모든 슬라이드에서 텍스트가 잘리거나 넘치지 않는가
- [ ] 줄바꿈 지점에서 단어가 끊기지 않았는가
- [ ] 폰트가 원티드산스로 정상 렌더링되었는가
